# Engine

3학기 팀 프로젝트 협업을 위한 엔진 프로젝트입니다. 
1학기 때 제작한 엔진을 기반으로 구조를 정리하고 개선하여 협업 시 참고할 수 있도록 구성했습니다.

## 🏗️ Architecture
현재 엔진은 `Engine`을 중심으로 주요 컴포넌트들이 연결되는 구조입니다.

현재 엔진은 `Engine`을 중심으로 `Level`, `Actor`, `Input`, `Collision`, `Renderer` 등이 연결되는 구조입니다.

코드를 처음 볼 때는 아래 흐름 위주로 보면 됩니다.

```text
Engine
  ↓
Level
  ↓
Actor
```

`Engine::Run()`에서 입력 처리, 초기화, 업데이트, 렌더링 순으로 게임 루프가 진행됩니다.

또한 엔진은 DLL 형태로 구성되어 있어, 게임 프로젝트에서 엔진 기능을 불러와 사용하는 구조입니다.

현재 포트폴리오용 리팩토링을 별도로 진행할 예정이라 소프트웨어 렌더링 및 일부 그래픽 기능은 제외되어 있습니다.

따라서 현재 버전은 완성된 실행본보다는 **엔진 구조와 기능을 참고하기 위한 협업용 버전**으로 봐주시면 됩니다.
